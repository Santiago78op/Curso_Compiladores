Proyecto 2 · Organización de Lenguajes y Compiladores 1

Un intérprete cliente-servidor, etapa por etapa

Teoría de compiladores aplicada a un stack distinto del habitual del curso: JavaScript, Jison, Express y React, en vez de Java, JFlex, CUP y JavaFX. Cada etapa es una presentación con sus diapositivas, ejemplos reales del proyecto y un quiz de cierre. Las 8 etapas están completas: el intérprete corre en el navegador.

  1. Etapa 0 Conceptos base y por qué cambia el stack: JS/Jison vs Java/JFlex+CUP ✓ completada
  2. Etapa 1 La gramática Jison: tabla de tokens y léxico en %lex ✓ completada
  3. Etapa 2 El parser: gramática sintáctica, precedencia y el AST ✓ completada
  4. Etapa 3 El intérprete: entorno, tipos y dos pasadas ✓ completada
  5. Etapa 4 Señales de control: break/continue/return y la auditoría de código ✓ completada
  6. Etapa 5 El servidor Express: contrato REST y entorno fresco ✓ completada
  7. Etapa 6 El cliente React: editor multipestaña, reportes y el AST con vis-network ✓ completada
  8. Etapa 7 Pruebas de extremo a extremo con Playwright ✓ completada
