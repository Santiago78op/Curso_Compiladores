Construyendo un intérprete, etapa por etapa

Teoría de compiladores explicada desde cero mientras se construye DataForge de verdad. Cada etapa es una presentación con sus diapositivas, ejemplos interactivos y quiz. Las 6 etapas están completas: el intérprete funciona.

  1. Etapa 0 Conceptos base: intérprete, tokens, lexema, patrón ✓ completada
  2. Etapa 1 Tabla de tokens + analizador léxico con JFlex ✓ completada
  3. Etapa 2 Gramática BNF + analizador sintáctico con CUP ✓ completada
  4. Etapa 3 Ejecución: variables, arreglos, aritmética y estadísticas ✓ completada
  5. Etapa 4 Editor con JavaFX: pestañas, abrir/guardar, consola ✓ completada
  6. Etapa 5 Gráficas (barras, pie, línea, histograma) ✓ completada
  7. Etapa 6 Reportes HTML + recuperación de errores en modo pánico ✓ completada

Profundizaciones

  1. ★ Gramáticas, muy claro — derivaciones, LL y LR, tabla predictiva, conflictos y precedencia ampliada
  2. ★ Autómatas, en movimiento — ER → Thompson → subconjuntos → simulación en vivo nuevo
  3. ★ La tabla de símbolos, a fondo — ámbitos encadenados vs. nuestro Entorno nuevo
  4. ★ El AST y cómo corre el código — traza real + evaluación directa vs. árbol nuevo
  5. ★ Las fases del compilador — el mapa del Cap. 1 y dónde vive cada fase en el proyecto nuevo
  6. ★ Análisis semántico y tipos — el sistema de tipos de DataForge formalizado + errores consolidados nuevo
  7. ★ Maven y los arquetipos — cómo se construye este proyecto: POM, ciclo de vida, y plantillas de proyecto nuevo

Cómo se trabajó este proyecto: DataForge se construyó con demostración guiada, paso a paso; los siguientes proyectos del curso (ConjAnalyzer, CompScript, CompInterpreter) se trabajaron con el estudiante escribiendo el código y el instructor revisando. El código de referencia vive en la carpeta DataForge/ del workspace.
