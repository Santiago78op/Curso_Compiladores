Construyendo un intérprete CON árbol, etapa por etapa

Teoría de compiladores explicada mientras se recorre CompScript, el proyecto hermano de DataForge que sí necesita un árbol de sintaxis abstracta: tiene if, while, for, funciones y recursión, y ninguna de esas construcciones se puede evaluar en una sola pasada del analizador sintáctico. Cada etapa es una presentación con sus diapositivas, ejemplos reales y quiz.

  2. Etapa 1 Tabla de tokens + analizador léxico con JFlex ✓ completada
  3. Etapa 2 Gramática BNF + analizador sintáctico con CUP ✓ completada
  4. Etapa 3 El árbol de sintaxis abstracta: ast/A.java ✓ completada
  5. Etapa 4 Tabla de símbolos: Contexto y Entorno, ámbitos anidados ✓ completada
  6. Etapa 5 Flujo de control: if / match / while / for / do-while ✓ completada
  7. Etapa 6 Funciones, argumentos por nombre y recursión ✓ completada
  8. Etapa 7 Editor JavaFX + los 5 reportes (tokens, errores, AST, símbolos) ✓ completada

Cómo se trabajó este proyecto: a diferencia de DataForge (construido con demostración guiada), en CompScript los roles se invirtieron: el estudiante escribió el código y el instructor tutoreó y revisó.
