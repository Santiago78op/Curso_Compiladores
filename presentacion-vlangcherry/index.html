Un intérprete en Go, etapa por etapa

Material de estudio para el equipo de VLangCherry: un intérprete del lenguaje "V-Lang Cherry" (tipos estáticos, structs con métodos por referencia, slices 1D/2D, control de flujo, recursión) construido con ANTLR4 sobre Go, con servidor REST y cliente React. El proyecto está completo y verificado.

  1. Etapa 0 Conceptos base: por qué ANTLR4 + Go, y no JFlex/CUP + Java ✓ completada
  2. Etapa 1 La gramática ANTLR4: lexer y parser combinados en un solo .g4 ✓ completada
  3. Etapa 2 Del parse tree al AST propio: por qué no se usó el Visitor generado ✓ completada
  4. Etapa 3 Tipos estáticos, structs y métodos "por referencia" gratis ✓ completada
  5. Etapa 4 Slices 1D/2D ✓ completada
  6. Etapa 5 Control de flujo, recursión y la auditoría de validación semántica ✓ completada
  7. Etapa 6 El servidor REST con net/http ✓ completada
  8. Etapa 7 El cliente React, reusando componentes ✓ completada

Sobre este proyecto: VLangCherry es el primer proyecto de OLC2 (curso distinto de OLC1) y es trabajo grupal de 3 integrantes, con defensa oral en vivo. Esta presentación es material de estudio para repasar las decisiones de diseño antes de esa defensa — no reemplaza al ManualTecnico.md ni a docs/gramatica.txt, que son la fuente de verdad técnica. El código de referencia vive en la carpeta VLangCherry/ del workspace.
