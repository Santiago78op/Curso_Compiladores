Un intérprete para la teoría de conjuntos, etapa por etapa

ConjAnalyzer lee conjuntos y operaciones escritos en notación prefija, los evalúa, los simplifica con las propiedades de la teoría de conjuntos y los dibuja como diagrama de Venn. Cada etapa es una presentación con sus diapositivas, ejemplos reales y quiz. Las 6 etapas están completas: el intérprete funciona, y ya pasó una auditoría de calidad.

  1. Etapa 0 Conceptos base: los conjuntos como lenguaje ✓ completada
  2. Etapa 1 Tabla de tokens + analizador léxico con JFlex ✓ completada
  3. Etapa 2 Gramática BNF + analizador sintáctico con CUP ✓ completada
  4. Etapa 3 Ejecución: conjuntos, operaciones y el árbol acotado NodoOperacion ✓ completada
  5. Etapa 4 El Simplificador: las 5 leyes algebraicas (sección 7) ✓ completada
  6. Etapa 5 Diagrama de Venn exacto, con Canvas ✓ completada
  7. Etapa 6 Reportes HTML + JSON de simplificación con Gson ✓ completada
